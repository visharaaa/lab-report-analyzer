# lab-report-analyzer

An LLM + RAG-based system for extracting, interpreting, and explaining
CBC, blood glucose, and HbA1c laboratory results in plain language.

## Project Scope

The initial version supports:

- Complete Blood Count (CBC)
- Blood glucose tests
- HbA1c

## Planned Pipeline

Laboratory Report
→ Text / OCR Extraction
→ Structured Results
→ Result Normalization
→ RAG Retrieval
→ LLM Explanation
→ Safety Validation
→ User Interface

## Tech Stack

- Python
- FastAPI
- Pandas
- RAG
- Sentence Transformers
- ChromaDB
- LLM API
- Streamlit
